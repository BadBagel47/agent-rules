# agent-rules

Shared rules for AI coding agents working in BadBagel47's repositories.

- `AGENTS.md` – the current rules (single source of truth)
- `templates/` – files agents copy into project repos (e.g. `auto-merge.yml`)
- `versions/` – archived earlier versions of the rules

Project repos reference the rules with a one-line `AGENTS.md`:

```
Read and follow the shared rules at https://raw.githubusercontent.com/BadBagel47/agent-rules/main/AGENTS.md before starting any work. If the link cannot be read, fetch AGENTS.md from the repo BadBagel47/agent-rules via GitHub instead. If neither works, say so immediately. Project-specific information is in HANDOFF.md.
```
