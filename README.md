# agent-rules

Global agent rules for AI coding agents working in BadBagel47's repositories. Rules for a single repo (project rules) live in that repo's AGENTS.md, below the reference to the global agent rules.

- `AGENTS.md` – the current rules (single source of truth)
- `templates/` – files agents copy into project repos (e.g. `auto-merge.yml`)
- `BACKLOG.md` – proposals for changes to the rules
- `drafts/AGENTS-next.md` – collected, not yet published changes (not in effect; only exists while changes are pending)
- `versions/` – archived earlier versions of the rules

Project repos start their `AGENTS.md` with this reference, followed by where HANDOFF.md and the backlog are and the project rules:

```
Read and follow the global agent rules at https://raw.githubusercontent.com/BadBagel47/agent-rules/main/AGENTS.md before starting any work. If the link cannot be read, fetch AGENTS.md from the repo BadBagel47/agent-rules via GitHub instead. If neither works, say so immediately. Project rules follow below; project information is in HANDOFF.md.
```
